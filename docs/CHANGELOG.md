# Lumi Portfolio Changelog

## Editorial Redesign v1 — July 30, 2026

### Overview

Rebuilt the public homepage to establish a more personal, artistic, and editorial portfolio direction for Lumi Huang as a Visual / Web Designer & Creative Developer.

### Added

- Full-screen editorial hero section
- About section
- Selected Works section
- Gallery section
- Contact section
- Responsive layouts for desktop, tablet, and mobile
- Subtle reveal animations
- Reduced-motion accessibility support
- Decorative sparkle motifs
- Pale pastel background atmospheres

### Changed

- Replaced the previous design-system demonstration homepage
- Updated the visual system toward expressive serif typography
- Introduced asymmetric layouts and increased whitespace
- Replaced rounded cards with open, sharp-edged compositions
- Updated site metadata
- Improved project presentation on smaller screens

### Removed

- Public design-token demonstration content
- Generic sample buttons and form cards
- Rounded card-heavy homepage presentation
- Template-like component showcase sections

### Validation

- `npm run lint` passed
- `npm run build` passed
- Local development server returned HTTP 200
