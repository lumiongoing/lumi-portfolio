# Lumi Huang Portfolio Website

## Goal
Build a clean, elegant, personal portfolio website for Lumi Huang.

The site should combine:
- Clear structure inspired by karolinahess.com
- Elegant, soft, refined visual feeling inspired by kynejang.com
- Original design only. Do not copy either reference website.

## Brand Positioning
Lumi Huang is a Designer × Developer × AI creative.

Title:
Visual Designer / Web Designer / Creative Developer

Core sentence:
I design, build, and refine thoughtful digital experiences with design, code, and AI.

## Pages
- Home
- About
- Works
- Gallery
- Contact

## Website Structure
Home, About, and Contact are sections on the same long scrolling page.
Works is a separate page.
Gallery is a separate page.

## Main User Goal
Visitors should quickly understand:
1. Who Lumi is
2. What Lumi creates
3. What Lumi’s style feels like
4. How to contact Lumi

## Priority
First build a stable skeleton.
Then unify visual style.
Then add subtle micro-interactions.
Then add scroll animations.
Avoid over-engineering.
