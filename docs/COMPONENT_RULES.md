Rules

Every component should be reusable.

Avoid duplicated code.

Props should stay simple.

Do not hardcode repeated content.

Use local JSON whenever possible.

---

Naming

PascalCase for components.

camelCase for variables.

Meaningful names only.

---

Spacing

Each section should have generous whitespace.

Avoid cramped layouts.

Use consistent padding.

---

Images

All images should support responsive sizes.

Never distort images.

Always keep aspect ratio.

Use Next/Image.
