# Design System

## Style Keywords
Elegant
Minimal
Editorial
Emotional
Clean
Soft
Professional
Creative but not chaotic

## Visual Direction
The site should feel refined, spacious, calm, and personal.
It should not feel like a corporate SaaS website.
It should not be overly colorful or tech-heavy.

## Layout
Use large whitespace.
Use asymmetrical but balanced layouts.
Use large typography.
Use simple navigation.
Use soft rounded containers when needed.

## Colors
Use a light neutral background.
Use mostly black / charcoal text.
Use one soft accent color only.
Avoid bright saturated colors.

## Typography
Typography should feel editorial and elegant.
Use strong hierarchy:
- Large hero text
- Medium section titles
- Small descriptive body text

## Motion
Use Framer Motion for subtle motion only:
- Fade in
- Slight upward movement
- Gentle hover movement
- Image scale on hover
- Smooth section reveal

Avoid:
- Heavy parallax
- Too many animations
- Overly playful effects
- Complicated cursor effects in v1
