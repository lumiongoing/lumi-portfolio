# Visual Language

This website should feel like a modern design exhibition.

The interface should never compete with the work itself.

The design should disappear, allowing the content to become the focus.

Every element should have room to breathe.

Whitespace is part of the design.

Large margins are encouraged.

Typography should create rhythm before decoration.

Use scale instead of color to create hierarchy.

Avoid unnecessary decoration.

Avoid visual noise.

Motion should feel like breathing.

Everything should move with intention.

Hover interactions should reward curiosity.

Scrolling should feel calm.

Nothing should surprise the user.

The experience should feel premium,
not flashy.

The website should communicate confidence through restraint.

Designer × Developer × AI should feel unified.

Do not create three separate identities.

Instead, present them as one creative workflow.

The website should feel handcrafted,
not generated.

Every page should feel consistent.

Every interaction should have a reason.
